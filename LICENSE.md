This is a private development repository containing new project code and
SDK-derived adaptations. No blanket license is assigned to the entire tree.
Existing copyright headers and license notices remain authoritative for their
respective files; absence of a header does not grant additional rights.

- Many retained Actions/Zephyr source files identify Apache-2.0 in their headers.
- minimp3 retains its original CC0 license in `third_party/minimp3/LICENSE`.
- miniz and libspng retain their upstream notices under `app/sdk/ui/svgrender/`.
- SDK libraries, stock binaries and media are external local inputs, not part of
  the Git repository or a license grant from this project.

Review per-file provenance and the applicable SDK terms before redistribution.
See `docs/third-party.md` for dependency boundaries.
